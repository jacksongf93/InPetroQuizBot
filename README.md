# InPetroQuizBot

Bot de quiz nativo do Telegram para o banco In Petro de Instrumentação.

## O que faz
- 40 questões IP-I-001 a IP-I-040
- randomiza os objetos completos das alternativas
- gera o card com a mesma ordem usada no quiz
- envia Quiz nativo A/B/C/D/E
- informa a alternativa correta e uma explicação curta
- avança automaticamente após a resposta

## Variável secreta
`TELEGRAM_BOT_TOKEN`

Nunca publique o token no repositório.
